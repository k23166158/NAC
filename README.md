## Third-Party Code and Dependencies
This software was built using the following major frameworks, libraries, and external tools. These tools were relied upon heavily for the core architecture, database management, and data generation:

* **Django (v6.0.1)**: The core Python web framework used to build the application, manage the database ORM, handle user authentication, and route URLs. 
  * *Location:* [https://www.djangoproject.com/](https://www.djangoproject.com/)
  
* **Faker**: Used heavily in the `seed.py` management command to generate massive amounts of realistic dummy data (users, names, support tickets, and text) for testing and population.
  * *Location:* [https://faker.readthedocs.io/](https://faker.readthedocs.io/)
 
* **Pillow** Used specifically for handling images within django databases to store and manage information about them.
   * *Location:* [https://pypi.org/project/pillow/](https://pypi.org/project/pillow/)

* **Coverage** Used frequently to ensure tests covered a high percentage of the code, reducing bugs massively.
   * *Location:* [https://coverage.readthedocs.io/en/7.13.4/](https://coverage.readthedocs.io/en/7.13.4/)

* **Python** The programming language used to develop the project.
   * *Location:* [https://www.python.org/](https://www.python.org/)
